# 🎵 SonicEquity Frontend

### *Next.js 14 + Tailwind + Soroban SDK High-Fidelity UI*

The frontend for SonicEquity is built with Next.js 14, TypeScript, Tailwind CSS, Framer Motion, and Recharts, matching the high-fidelity obsidian glassmorphism design system.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run Next.js Development Server
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
